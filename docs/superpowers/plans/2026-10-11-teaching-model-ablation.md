# 教学决策三组有界对照

用户授权：只比较教学决策，语音与正式应用配置不动。执行窗口 2026-10-11 17:21:16–17:56:16 UTC，最多30次决策请求，无自动重试、无修复调用、无额外模型裁判。

## 实验设计

- A：qwen3.8-omni-flash-realtime + 当前完整提示。
- B：qwen3.8-omni-flash + 相同完整提示，reasoning_effort=medium。
- C：相同 Realtime + 精简提示，保留相同题目、课程、权限、历史、图片和 JSON 契约。
- 8个存档现场×3组=24次；植树漏起点与面积求解释两个现场，根据实际回复各续聊一次×3组=6次。失败保留，不挑好答案重跑；接口不可用直接报告，不换模型。
- 所有输出来自真实接口。历史样本的孩子输入与图片是此前验收模拟材料，不是真实儿童学习效果证据。

## 固定样本

1. 小数乘法：孩子已建立分份对应，老师不应抢算最终1.44。
2. 面积：明确追问为什么，不能回声反问或只背底乘高。
3. 面积恢复：最新已改24，旧照片40不能变成当前答案。
4. 植树：漏0米，5到10米只有一个间隔，不能附和数学错误。
5. 植树质疑：孩子指出老师错误，应明确承认并订正，而非只表扬孩子。
6. 除法：只改变除数，不能认可错商；按五上同时扩大思路。
7. 除法新思路：孩子换成分米，应接住单位解释，不退回机械反问。
8. 方程恢复：已解出并代回，不重新要求解方程。

## 评分和测量（调用前冻结）

每项0/1/2分：数学正确、证据时序、回应当前困难、独立性与课程适切、自然连续性，总分10。0=失败，1=部分，2=满足。错误数学/抢答/伪造当前证据列为硬失败，不能以其他高分抵消。现有结构与权限校验单独报告，不以其通过冒充教学通过。单人定性评审，单次采样，不声称统计显著或真实教学有效。

记录：输入/图片/提示哈希、原始JSON输出、校验结果、完整决策墙钟延迟、usage、思考Token（如返回）、官方标价估算费用。未知用量或费用保留null，不计作免费。只记录最终回复，不保存模型思维链。价格以北京官方表为准，包含思考输出；未包含语音费用、优惠与免费额。

1. 先编写并观察失败测试：历史截断无未来泄漏、精简提示事实不丢、SSE跨块解析、用量/成本缺失、持久调用上限。
2. 编写隔离脚本，从存档重建决策前快照，核对图片哈希。输出放私有验收目录，不写家庭作品、不启动语音。
3. Mac mini调用，交错组别顺序；每次请求先持久记账，45秒外层超时（现有Realtime内层30秒），总截止时间硬限制。

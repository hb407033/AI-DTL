# 互动老师：本地配置与成人验收

这一模式只需要千问，不需要 Pi provider/model。旧 `ai:check` 仍检查两条路线，不能用其中 Pi 缺失判定互动老师不可用。

1. 在项目根目录复制 `.env.ai.example` 为 `.env.ai.local`，在本机编辑：
   - `DASHSCOPE_API_KEY`：新申请的北京地域 Key；撤销之前发到聊天中的旧 Key。
   - `AI_DTL_QWEN_WORKSPACE_ID`：对应百炼业务空间 ID。
   - Pi 三项可留空。
2. 停止并重新运行 `pnpm host:simple`，让进程读取新配置。`http://127.0.0.1:8790/healthz` 返回 configured=true 只证明配置格式，不证明授权。
3. iPad 的“互动老师”输入这台 Mac 的局域网 IP，点连接。服务器只有客户端连接时才建立云端连接并可能产生费用。
4. 家长先试：写题→点击“开始连续对话”→直接说话。停顿约 1.2 秒自动发送；老师播放结束后约 400ms 自动继续听，不必逐轮按键。自动模式发送提交时的画布快照；单轮最多 30 秒。手动按钮保留作调试入口。
5. 连续十轮测试，看是否能结合笔迹、保持上下文；播放时点“停止”应立即停声。当前是轮流说话，老师播放时不录音，不支持语音打断。停止、切页或进入后台会断开通道；重新连接是新对话。每次开麦后 90 秒仍未完成一句话则断开，会话总时限仍为 20 分钟。

## 用量和静音

- 静音只在 iPad 保留最多 400ms 前滚；未检测到足够持续发声不上传，不产生空回合。能量检测不是语音识别，电视或旁人讲话仍可能被触发，须在安静环境真机验收。
- 显示本次连接的轮数、已提交音频秒数，以及千问实际返回的输入/输出 Token 累计。缺失用量明确标记，不视为零。Token 统计不是人民币账单；历史上下文会影响消耗，不按连接秒数推算费用。
- 本版每轮仍发送一次当前画布，尚未启用“仅变化时发图”，避免未经验证地丢失视觉上下文。
- 官方用量字段依据：https://help.aliyun.com/zh/model-studio/server-events （response.done，2026-09-16 核实）。

## 诚实边界

- 千问直接回应，不经过教学内核逐句审核。需家长在场；提示词不能保证永不提前解题。
- 当前画布保存在视图内存；本试用入口尚未接入重启恢复。退出 App 前自行保留重要内容。
- 不建立根因、掌握程度或长期成长记录；宿主不落盘音频和画布。服务商侧处理遵循其 API 条款，不等于数据从未离开本机。
- 没有 Key 时只验证本地协议和构建，不提供伪装成真实 AI 的演示回复。

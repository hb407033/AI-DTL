# 教学焦点修复执行计划

用户已确认继续直接实施。沿用千问、Swift/PencilKit、当前分支；不提交、不改学习档案数据模型。

目标：孩子明确报告计算结果时，不能退回追问题目已知条件。采用保守的本地教学动作选择，不把选择动作当成答案正确或掌握判断。模糊、否定、求助、疑问不命中该规则；原有权限和单次接续不变。

实测发现将“看看我的想法”的录音再次送入播报任务，模型仍回答录音；同一要求以静音占位输入则能准确播报。选定动作后只让千问播报系统问题，不重复上传原录音/旧画布；真实原话和画布仍保存为证据。播报完整缓存，文本匹配选定问题后才播放，最多一次未播放草稿重生成；仍不匹配就保留未完成，不伪造音频。

- [x] `workspace-teaching-context.ts`：选择 ask_reason / invite_check，保留来源 turnId；测试明确结果、错误结果、已有理由、未知/否定/题干复述、语音文本匹配。
- [x] `workspace-voice-route.ts`：仅 review 且不是接续时选焦点；静音占位播报、无图像、原证据保留；沿用有界缓存和取消保护。集成测试验证未经检查的语音不发给孩子。
- [x] 运行相关单测、类型检查；真实五轮合成输入验证最终问题和实际音频，再跑真机照片/书写/恢复/冲突/横屏完整流程。
- [x] 核对实际回复，留存证据，停止夹具服务并正常启动 App。

本地规则覆盖显式表达，不声称解决全部自然语言；不因关键词推断孩子会不会。技能按 brainstorming 的已确认范围收敛、writing-plans 记录、executing-plans/TDD/verification 在当前会话串行执行。

# 自然学习闭环：执行及验收

用户确认终点：跑通一个真正自然的学习闭环，并留下可检查证据。沿用当前 Swift/PencilKit + Mac 宿主 + 千问，不换模型、不提交推送。

## 本轮设计

孩子表达 → 主动请老师查看 → 老师针对表达提问 → 孩子直接回答（不重复口令） → 老师回应并退出 → 孩子再次尝试 → 主动请老师查看 → 保存并重开恢复。

从明确的 review/help 授权派生一次后续回答机会，限定同题同版本、五分钟内、上一反馈未被异议且仍是最后反馈；仅下一轮有声音且非暂停/否定/休息表达时使用。一次消耗，不由后续回复继续续期。打断、纠正、失败、退出、重连作废。不会自行升级为 help，不因静默/书写触发。

一个选择问题可包含两个问号；验收依据教学动作是否同一焦点，不按标点数量判自然程度。保留原先失败记录。新闭环独立验证，不删减旧权限/异议/恢复测试。

## 实际调整与结果

接续回答改成单独的短任务提示，云端教学会话与内部转写会话隔离，iPad 本地对话连接保持。接续音频先缓存，非空、长度及无追问检查通过才播放；不合规最多重新生成一次，仍不合规则保留未完成记录，不播放草稿。此门禁是格式/收尾保护，不冒充通用语义审查。

2026-09-21 17:55 真机最终闭环通过，耗时 111.575 秒；相关后端 35 测试通过。实际回复与三份证据已核对。见 `docs/handoffs/2026-09-21-ai-dtl-natural-loop-results.md`。这是一个可检查的功能闭环；偶发云端断连、响应速度和真人自然度仍待改善。

边界：这是单个合成孩子情境的真实设备/模型闭环，不证明真人长期教学有效，也不冒称 AI 图形生成、长期学习记忆已完成。技能沿用 executing-plans、TDD、verification；合成输入用现有 macOS 本地声音，不使用 ElevenLabs（不新增供应商/密钥）。

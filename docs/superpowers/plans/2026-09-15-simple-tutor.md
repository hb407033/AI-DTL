# 单模型互动白板执行计划

用户已确认：按键说话 + 当前画布 + 千问直接回应；暂停 Pi、根因判定、成长档案在主路径的接入。保留旧实现。按 writing-plans / executing-plans / TDD 执行，不另建平台、不自动委托、不提交既有修改。

**目标：** iPad 五轮语音与画布对话无需后台救场。云端资格未验证前不称完成。

**实现：** 独立本地主机端口 8790，单 WebSocket 转接一个千问会话，手动回合；原生 AVAudioEngine 录音、PCM 播放、PencilKit 快照。仅内存对话，无长期能力结论。家长在场；界面说明画布与语音发往千问、模型可能出错。停止按钮关闭整个通道并立即停声，重新连接开始新对话。

- [ ] apps/agent-host/src/ai/simple-tutor.ts：限定 ready/recording/replying 状态，录音最多 30 秒、图片最多 2MB、会话最多 20 分钟、关闭两侧连接；收到 commit 确认后才 response.create；服务端持有 Key。
- [ ] apps/agent-host/test/simple-tutor.test.ts：本地 WebSocket 假服务验证图片/音频顺序、五轮复用、断开清理、配置缺失不连接。
- [ ] apps/ipad/ScholarPad/ScholarPad/Session/SimpleTutorView.swift：白板、点击开始/结束说话、停止、主机地址；不引入网页或新依赖。
- [ ] 原生构建与相关测试；连真机、填新 Key 后成人五轮验收。没有 Key 时只完成无云端验证，不覆盖旧 App 构建与资料。

协议依据：https://help.aliyun.com/zh/model-studio/realtime （2026-09-15）。图片必须在至少一帧音频之后提交。输入 PCM16 16kHz，输出 PCM16 24kHz。该路径直接播放模型输出，不宣称经过教学内核审核。

# AI-DTL 第一版范围调整：先交付自然学习闭环

日期：2026-10-07。状态：依据用户本轮授权调整范围；尚未实施、尚未验收。

## 1. 不变的使命与调整的顺序

品牌名称严格保留“AI 学科心智学习系统”。面向人教版五年级上册，以孩子自己的问题、说写画和理由为起点；老师依据证据给予最少必要帮助，不用答对一次证明掌握，不贴“粗心”等能力标签。

第一版先证明孩子能够自然使用，再建设跨周成长分析。通用性体现为客户端、教学策略、存储和模型边界清晰，不提前实现所有学科与平台功能。

## 2. 第一阶段唯一交付

孩子打开 iPad，连接家中的 Mac mini，拍一道题并核对题意，独立写画；主动开启老师对话后连续交流，纠正一次理解、暂停并继续；退出重开能保留原题和原稿。整个过程不依赖开发者临时修服务、改地址或重新安装。

阶段完成指工程体验可用，不等于儿童学习效果或跨周 AI 退出已得到证明。

## 3. 架构收敛

| 部分 | 第一阶段职责 |
| --- | --- |
| iPad 原生 App | 拍照、PencilKit、录音播放、即时状态、本地草稿 |
| Mac mini AI-DTL 宿主 | 自动发现、会话、教学约束、工作区持久化、模型调用、用量 |
| 现有千问 Omni | 已选模型的转写、教学回复与语音；不切换供应商 |

唯一儿童入口为 `LearningWorkspaceView`；唯一发布宿主为 `pnpm host:learning`，端口 8791。旧宿主和探针保留用于回归，但不成为第二个儿童产品，也不承诺当前工作空间已接入旧成长账本。

Mac mini `10.10.10.6` 为主实施机；宿主保持单进程写入。HTTP/WS 仅用于家庭局域网，不扩展到公网。

## 4. 两种行为，不增加两套页面

- 独立探索：默认状态，不开麦、不主动调用模型、不因停顿催促。孩子自由写画。
- 老师对话：孩子点击一次“和老师聊”后，授权当前题意版本内的澄清、回应与询问理由；不要求每轮重新说固定口令或点击求助。
- 一次对话授权不等于无限制给提示。明确求助才给一步提示；不主动给最终答案，不自动升级提示，也不生成长期能力判断。
- 题目或题意版本变更、暂停、进入后台、连接中断后，授权失效；恢复作品不能自动开麦。
- 第一期保留半双工，老师说话时提供常驻“打断”按钮。不能把半双工称为语音随时插话；AEC、全双工留到后续。
- 老师每轮接住一处表达，最多一个问题或一步提示；普通回应与长期成长结论分开。

## 5. 必须保留与明确后置

必须保留：题意核对、原图、孩子原稿与教师图分离、纠正后旧结论失效、异步结果版本校验、失败不丢稿、取消后不复播、不开麦恢复。

第一阶段不新增：Hermes/Pi 接入、通用 Agent 平台、完整成长账本接线、自动根因评级、复习调度、多孩子账户、跨设备协作、新学科、新图形引擎、模型价格对比迁移。已有线段辅助图作为回归保留，不扩大范围。

已有数据及旧实现不删除、不迁移为新格式；必要的会话协议扩展保持旧客户端默认行为。

## 6. 交付与验证边界

每项改动的单测是保护，不代替整机交付。技术验收在同一构建、同一真实 iPad、同一 mini 宿主上完成；模型、麦克风、播放、画布、持久化均在同一条链路里。

合成音频注入证明软件链路；扬声器播放合成输入并由 iPad 麦克风采集，可验证声学工程链路，但仍不是儿童学习效果。真人 Pencil 与孩子实际试用单列，不能以自动化触控冒充。

同一次发布记录源码基线及差异指纹、宿主版本、App 构建、测试结果和已知限制。没有新增任务授权时，实施者不顺手接 Hermes 或扩展成长系统。

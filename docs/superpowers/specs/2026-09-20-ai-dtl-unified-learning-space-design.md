# AI-DTL：统一学习空间与拍照探索

状态：2026-09-20 对话中的产品选择已获用户确认；本文为书面收敛稿，尚不代表实现完成。

## 1. 使命与本次纠偏

品牌固定为 **AI-DTL / AI 学科心智学习系统**，英文为 AI-Powered System for Disciplinary Thinking and Learning。

目标是发展学科思维：孩子建立表达、提出猜想、解释依据、验证并迁移，AI 根据证据介入并逐渐退出。不是拍照搜答案，也不是把做题数量当成长。

当前三个产品入口把语音、教学流程、画布能力分散了。新版本只向孩子呈现一个学习空间；旧页面保留在调试入口以便回归，不再独立扩展。不丢弃已有实现，不新增 Agent 平台。

本稿在以下范围取代 2026-09-17 的分数闭环设计：允许拍照带题，分数不再是产品边界；持续语音不再仅停留在独立互动老师页面。原有证据绑定、提示分层、异议、保存确认与独立迁移原则继续有效。

## 2. 已确认的产品选择

| 事项 | 决定 |
| --- | --- |
| 学习入口 | 带题来探索、今天探索，共用同一空间与老师 |
| 带题方式 | **直接拍照**；第一版不增设相册选图或文字导题入口 |
| 学科范围 | 小学数学开放题型，先验收文字题、计算题、简单配图题；复杂几何不承诺 |
| 教学阶段 | 人教版五年级上册；家长设置当前单元，系统保存 |
| 介入方式 | 开启后可持续语音交流；主动提交/求助才分析作答或给提示 |
| 画布 | Pencil 自由手写＋可操作数学图形＋辅助情境图片；提示与原稿分层 |
| 记忆 | 学习事实与下次衔接，不做长期能力标签或自动掌握判定 |
| 技术 | Swift/PencilKit、Mac 本地宿主、现有千问 Omni；不换模型平台 |

当前单元不是整本书已掌握的证明。之前的内容仅视为可能接触过，必要时问“这个学过吗”。可回到前置概念，不为快速解题引入高年级公式。课程进度约束知识跨度，不限制思考深度。教材版本及单元名称以家庭实际课本/家长设置为准，不凭记忆预置完整目录。

## 3. 一段完整体验

1. 孩子选择“带题来探索”，打开相机，对准一道题拍照。照片先在本机预览，可重拍；取消不产生学习题目或调用模型。
2. 孩子确认使用照片后，上传选定照片给现有模型识别题意。展示原图和读到的题目，询问是否一致，暂不解题。
3. 模糊、漏条件、多题混拍时请孩子重拍或口头指出目标题；不猜数值、不静默拼条件。可口头纠正识别结果，这不等于增加文字导题入口。
4. 题意确认后进入同一学习空间：题目、画布、语音。孩子独立画写，也可以询问题意或解释自己的想法。
5. 老师回应交流，但只有孩子明确邀请分析或求助时才评判作答、给提示。老师先说明实际看到/听到的证据；不清楚则询问，不套用题干冒充孩子的想法。
6. 每次最多一个追问或一小步提示。孩子说“不是这个意思”或按“你理解错了”，停止旧反馈、记录纠正，旧推测不得作为事实继续使用。
7. 孩子继续修改、解释、验证；需要时隐藏提示，邀请独立处理一个小变化。允许拒绝、休息，不强制无限闯关。回答正确不等于长期掌握。
8. 结束前保存照片引用、确认题意、原稿、已提交解释、提示、未解决问题。收到保存确认才能显示已保存。下次手动继续，不自动开麦或续播。

“今天探索”把现有审核过的题包转换成相同的问题描述，之后走同一流程。首版不根据模型推测的能力画像自动排课。

## 4. 持续交流与主动介入

用户主动开启语音后，不必每轮重新连接或点“和老师说”。麦克风状态始终可见，随时暂停；后台、离开空间或休息时停止录音，恢复必须手动开启。

语音轮次分四类：

- 孩子在表达/思考：保留当前轮的表达，不自动评价对错，不主动补解法。
- 孩子直接询问题意或词义：允许简短回应，但不自动升级到作答诊断。
- “看看我的想法”“这样对吗”：冻结本轮语音、题目和画布证据，分析当前表达。
- “我卡住了”“给我一点提示”：根据当前证据给一小步帮助；记录本次使用了提示。

停顿检测只是划分音频轮次，不等于教学授权。语意不明确时问一句确认；按钮作为同等入口保留，不能让语音路径绕过同一教学策略。

首个工程门禁是验证现有 Omni 能否在不先播出教学回答的情况下提供可靠的转写/意图控制。不能只写系统提示词就声称有严格门禁；若现有接口做不到，报告证据与具体限制，不擅自引入其他模型，也不假称连续语音已完成。

首阶段允许轮流说话和按钮停止播放，不把全双工/AEC 完善设为所有工作的前提；须明确播放时能否收音，不能虚假展示“正在听”。

## 5. 画布与证据

保留孩子 PencilKit 原稿；教学图形为有类型、可校验的对象。先按实际题目增加线段图、数轴、等分图、关系图，不先建设任意绘图引擎。

AI 只能改自己的提示层，孩子可以隐藏提示并继续作答。需要孩子操作的对象必须明确复制/交给孩子，不能静默改原稿。

情境图片用于想象场景，不把生成图片中的数量、长度当精确数学依据。生成能力与供应接口单独验证；当前 Omni 图片输入不等于支持图片输出。该能力不阻塞第一阶段，也不能偷偷添加收费供应商。

证据分开保存：题目照片、已确认题意、原始 PKDrawing、结构化图形、提交时合成预览、孩子转写、AI 可见反馈。图片不能写入 PKDrawing 字段。提交使用不可变快照，响应绑定 sessionId/submissionId/revision；旧反馈不得覆盖当前编辑。

## 6. 最小架构与复用

- iPad：一个学习空间，负责相机、画布、语音采集播放、事实展示、本地草稿。
- Mac：一个学习会话权威，负责题目来源适配、阶段/单元约束、教学动作门禁、模型连接、存档与恢复。
- 千问 Omni：理解图片/语音、讲解与请求图形工具；不直接写长期学习记录或孩子原稿。

复用 SimpleTutor 的音频生命周期与连续轮次经验，复用 LearningTutor 的显式提交/工具动作/版本校验。不把两套 WebSocket 同时连到同一学习过程，也不直接沿用“所有停顿都发起教学回答”。

最小问题描述包含：problemId、source（camera/curated）、照片引用（拍照题）、待确认/已确认题意、题包引用（预置题）、学习阶段快照。开放题不要求伪造 fraction challengeId 或预先知道标准答案。现有分数题是回归样例，不是协议分支。

## 7. 记录与异常边界

学习数据权威副本在 Mac；iPad 保留未同步草稿。选定照片、语音等需要传给云模型处理，因此“本地保存”不等于“不出设备”，首次使用要以孩子/家长能理解的方式说明。无关相册不读取，原始录音不长期保存，日志不打印照片正文、密钥或孩子完整对话。

识别失败保留照片并允许重试；模型断连保留画布，不自动重放旧提交。保存失败显示未同步；删除失败不能显示成功。恢复从事实重建上下文，不假装恢复原云连接或补播旧回答。现有旧草稿仍可读，不覆盖、不删除以简化迁移。

## 8. 分阶段交付与验收

### 阶段一：真实题目与连续说写

拍照 → 题意确认 → 独立说写 → 主动邀请老师 → 基于证据回应 → 再次表达。至少同题连续五轮不需要重连；覆盖一次误读纠正、一次明确求助、一次安静写画。最小保存和恢复必须可用，不能等第三阶段才防丢稿。

### 阶段二：可操作表达与独立尝试

围绕实际题目接入必要教学图形，验证数值/等分正确、孩子原稿不变、提示可隐藏、孩子能继续操作与探索小变化。图片生成先探针后接入，不扩展为通用素材平台。

### 阶段三：学习连续性与第二入口

完整恢复题目、原稿、已提交解释、提示和未解决问题；“今天探索”进入同一个空间。验收退出 App、后台、宿主重启、短断网；不做能力画像或自动每日推送。

每阶段都交付真机可操作结果。单元/协议、合成云端、真机自动化、真人教学分开记录。成人先走五轮，再由家长陪伴孩子体验；不把有回复、测试通过、答对一题当作使命完成。

核心观察项：老师是否基于证据；孩子能否解释理由；提示撤去后能否继续；对同类问题需要的提示是否逐渐减少。首版只记录事实，不根据少量样本宣称成长趋势。

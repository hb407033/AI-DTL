# AI-DTL 教学决策三组对照结果

## 结论

这批现场中，非实时 `qwen3.8-omni-flash`、`reasoning_effort=medium` 的首轮教学决策明显更贴近孩子的当前表达，值得作为下一步教学决策候选；不能直接宣布整体教学已达标。继续追问时，它也出现了抢答和含混的几何比喻。仅压缩 Realtime 提示没有改善教学，虽然省用量，但还出现虚构当前画面。

没有修改正式语音、正式模型配置或家庭作品；没有安装新版本。本次是隔离的真实模型比较，不是完整生产链路验收。

## 可检查的差别

### 1. 孩子已建立分份对应，谁抢算1.44？

孩子只说明1千克分十份、每份0.36元、取四份，并问对应是否正确。

- A主动给出“一点四四元”，再让孩子核对旧的小数点错误。
- C主动给出“取四份就是1.44元”。
- B确认“每份重量配每份钱数”，让孩子自己把四个0.36相加，没有报最终结果。

三者都通过轻量校验；这不代表三者都符合不抢答的教学要求。

### 2. 孩子指出老师5到10米间隔说错

- A让孩子再算60米间隔数，但孩子已经说明是12个；没有回应老师自己的错误。
- C只表扬并重复13棵，没有承认先前错误。
- B回应“你纠正得对，5到10米确实只有一个间隔”，继续承接孩子的0、5、10检验。

### 3. 旧照片40与最新口述24

三组当前完整/精简提示均未再把40当最新答案。但A/C逐字重复上一轮退出语，B具体承接斜边非宽和剪拼后的底高。这说明来源时序提示有帮助，不说明恢复教学已经完美。

### 4. 思考模型也会失败，不能裸接

B面积首轮以压扁花坛、观察高与格子数变化回应“为什么”，比只重述垂直定义更有讨论价值，但103字超过当前90字门禁，不能直接播放。

B续聊给出“高3到斜边5多出来那截就是歪出去的”这种含混比喻，主动报出40与24，孩子此时尚未算出24。该回复82字、通过现有轻量校验，仍判抢答；几何长度差也不能直接当作图上歪出去的部分或面积证明。

A植树续聊在孩子明确再次求助后，仍重复“树比间隔多1”和重算原题的任务，没有给小动作，并出现 `handoffMustBe_false`。C虽通过全部轻量校验，植树首轮却把只画了5、10两棵说成已经画了起点三棵。

## 对实现的建议（本次未实施）

1. 教学决策候选优先B，保留现有语音。不要仅靠更长提示或换模型来承诺解决教学质量。
2. 保留生产路径现有的结构校验与有限抢答复核，不因B首轮分高就删除。先把本次B面积抢答、A反复求助不响应、C虚构画面固定成回归样本。
3. 明确区分“决策内部分析”与“给孩子的下一句”；把原因解释落实为一个可观察的小动作，不能用90字压缩替代教学设计，也不直接扩大播报上限。处理超长应定点改写且继续防抢答，不生成新数学结论。
4. B中位决策约9秒、最慢14秒，需要明确的思考状态与可取消操作；不能用填充语音掩盖等待。本次没测音频端到端体验，暂不全量切换。
5. 下一轮应在同一小组固定样本上验证上述两条新失败及等待体验，再决定生产配置；不要扩张成新Agent平台或无上限评测。

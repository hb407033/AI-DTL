# 旧作品换主机后无法继续对话：修复与验收

## 实际原因

iPad 当前家庭草稿的作品 ID 为 `f829e42e-f214-4b50-afd9-22d74f9e97c0`。笔记本学习主机可读取 revision 24，Mac mini 返回 `404 / missing`。iPad 已切到 mini，但这份作品尚未随主机切换迁移。语音路由把缺档当作普通失败，客户端只提示“本轮未完成，原稿保留，请重新开启”，同一主机重试无法恢复。

## 已做的最小修复

- 语音路由分别返回 `recordMissing`、`recordCorrupt`；缺失、删除、损坏的作品不会触发模型或被自动重建。
- 客户端显示具体原因，并提供“检查主机”入口；关闭主机设置后恢复“一起聊聊”，不陷入重复打开设置的死循环。普通连接失败提供“重试对话”。原稿与笔迹不清空。
- 接受较新服务端记录时，清除已过期的待保存快照，避免随后保存拿旧反馈覆盖老师的新回复；实际本地画布另行保留。
- 仅将上述一份作品和 11 个媒体附件复制到 mini 正式作品目录。先冻结源副本，校验每个附件摘要；遇到目标记录、删除标记或已有媒体目录即拒绝，不覆盖。未迁移其他作品、权限或教学批准信息。

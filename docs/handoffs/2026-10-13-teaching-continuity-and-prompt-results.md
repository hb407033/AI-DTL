## 实现

- 后端只对已授权、正在生成的同一回复返回可恢复错误，包含 turnId、responseId 和权威作品版本。回复被拒绝、超时或语音不符只结束本轮，不关闭整段会话、不自动重发录音、不保存为有效反馈。权限错误、坏档和过期作品仍不可恢复。
- iPad 校验轮次、回复、作品身份及版本；取消本轮播放/思考，保留原稿、聊天和最近表达，恢复监听而不增加成功轮数。退出或正在打断时不能重新开麦。
- 恢复回执读取期间保留 ended 轮次身份，保证此时点击打断/退出仍能取得 interrupted 屏障，不被误判 staleTurn。
- 全 JSON 围栏可以作为完整格式包装解析；不从夹带说明或多个对象的文本中捞 JSON。空回复有明确修复要求；已解析草稿保留完整对象，不再在 2000 字处截断后无法压缩。
- 单问编辑只输出 utterance 补丁；漏引当前证据且多问时，同一个有界补丁修复这两处。宿主冻结其他字段，仍执行严格决策校验和语义复核，不增加重试次数。
- 交还编辑是短中文任务；宿主固定 return/true，兼容合法 JSON 也不能撤回状态。禁止增加原稿或当前孩子没有提供的数量、改变观察/证据或宣布掌握。“试一试/核对一下”不误当新增数学数量，“6米/六米”负例仍拒绝。
- 优先判交还语句与焦点的冲突，再判 handoff 布尔值，避免只把 true 改 false 后下一次又因交还语句被拒绝。
- 两个窄范围词形补漏：一本故事书的找零题、米的彩带。仍拒绝额外数量、额外条件、未支持书名、剩余问题及非整段条件；未扩展成任意题目解析。数学复核明确旧错式不能覆盖孩子当前明确修正。

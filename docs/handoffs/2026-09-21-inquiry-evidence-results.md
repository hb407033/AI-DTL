# 想法—笔迹证据—老师上下文：进展及继续入口

完整目标保持 active，本轮有代码与真实模型证据进展，不是整体完成。

## 当前实现

- POST `/workspace/:id/evidence`：孩子独立保存快照，不创建教师反馈；验证题目版本和媒体引用，按提交 ID 幂等，CAS 避免覆盖。
- iPad “把这次笔迹留作证据”：不要求先请老师点评。已上传且待确认的快照身份保存进 WorkspaceCache，跨重启重试同一份，不随新笔迹变动。上传前失败会明确说明重试截取届时画布，不声称保存了不存在的快照。
- 作品页明确选择证据，展开查看保存时的图；选择随草稿恢复和修订保留。旧草稿兼容可选 evidenceIds。保存记录引用的快照也能展开。
- `inquiryForTeaching`：只提供近期仍有效的孩子表达，不将父母记录当成孩子原话，不提供掌握/根因标签。最多六条，文本有界；引用编号不能视为已经看到旧图。
- 真实语音路由已经把 childInquiry 加入教学请求。集成测试检查实际发送的上下文，而不只测辅助函数。
- 真实千问第一次五轮探针在收尾中继续追问，被规则拦截。第二次收尾改为同一模型的严格中性语音播报（仅当第一稿不合格时），仍做逐字验收与音频缓冲，失败稿不播放。正常第一稿仍可具体承接孩子。

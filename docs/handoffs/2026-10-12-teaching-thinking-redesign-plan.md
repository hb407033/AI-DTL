# 教学思维引导能力改造方案（诊断 + 分层实施）

日期：2026-10-12
状态：方案待确认，未实施
前置证据：`docs/handoffs/2026-10-11-teaching-model-ablation-results.md`（三组教学决策消融）

## 问题陈述

系统已能对话问答，但不能像顶级数学老师那样带孩子建立数学思维方式，且会犯低级错误（抢答报答案、虚构画面、不回应孩子纠正、含混比喻）。消融实验证明：同一 Omni 模型，非实时 + `reasoning_effort=medium` 首轮决策 9.75/10，Realtime 完整提示仅 7.13/10——**问题不在模型能力，在链路设计**。

## 一、核心诊断

当前生产链路把模型教学判断所需的三样东西都拿掉了：**思考时间、数学真值、对孩子思维过程的可见性**。

### 1. 抢答（直接报答案）

- 生产决策调用走 `qwen3.8-omni-flash-realtime` 纯文本直出（`apps/agent-host/src/ai/config.ts:17`），提示词明令"不输出思维链"（`apps/agent-host/src/ai/workspace-teaching-decision.ts:77`）。教学判断被压缩成零思考的一次前向生成。消融 B 路径（非实时 + medium thinking）只在实验脚本 `apps/agent-host/scripts/probe-teaching-ablation.ts` 存在，未接入生产。
- 防抢答门禁是正则级别的：`validateTeachingDecision`（`workspace-teaching-decision.ts:131-232`）的 `answerLeak`、`wrongAnswerPraise` 等全部只对"整数÷一位小数"单题型生效（`apps/agent-host/src/learning/decimal-division-policy.ts` 正则只认 `(\d+\.?\d*)÷(\d+\.\d+)`）。植树、面积、方程题只能靠提示词自觉。代码注释自承："这不是完整的语义防抢答"（`:171-172`）。
- 唯一泛化兜底是同模型抢答复核器（`:306-320`），且其 prompt 明文**"不解整题"**——复核器不知道正确答案，无法判断数学对错。注释自承："同一模型的复核不是数学真值"（`:305`）。

### 2. 数学错误 / 含混比喻

- 全系统没有任何数学正确性验证：无独立校验模型、无符号计算、无 CAS。小数除法答案用 JS 浮点 `a/b`，其他题型连这个都没有。

### 3. 不回应孩子的纠正

- focus 枚举 `clarify|transformation|invariance|place_value|verify|transfer|return` 中**没有"承认老师自己错了"的状态**。孩子纠正老师时走 `correct → clarification` 权限（`workspace-voice-route.ts:188-206`），模型只能套澄清模板——消融中 A 组"孩子纠正 5 到 10 米间隔错误，老师不理会继续布置新任务"即此结构性缺失。

### 4. 虚构画面

- 图片只在授权轮附给模型（≤180KB 压平 JPEG），恢复轮/历史轮无图却要求承接旧观察，全靠提示词纪律约束，无机制核对。消融 C 组"把只画了 5、10 两棵说成已画三棵"即实例。

### 5. 教学机械、不像顶级老师

- 提示词是 40+ 条平铺规则堆叠（`buildDecisionPrompt`，`workspace-teaching-decision.ts:76-128`），本质是历年失败案例的补丁清单。规则互相冲突时（"最多 90 字" vs "完整承接"），零思考模型倾向最短路径——直接给结论。消融中 B 组 103 字的好回复被 90 字硬门禁拒掉，暴露这一结构矛盾。
- `packages/plugin-math` 已定义思维框架：`thinkingMoves: [conjecture, model, experiment, argue, verify, transfer]` + 五类根因断点假设（representation / intuition / strategy / rigor_chain / verification gap，`decimal-multiplication.ts:124,130-136`），但**只接在旧 kernel 链路，workspace 生产决策链路完全未使用**。思维方式教学目前只是 manifest 占位标签。

### 6. 模型看不到孩子的思考过程

- 上行是结构化笔画事件（`apps/ipad` 端 `StrokeDiff.swift`，hash+bounds+时序），但给模型的是压平静态图。顶级家教靠"孩子怎么下笔、哪里犹豫、涂改了什么"诊断思维——这些信号已采集但未喂给模型。

## 二、解决方案：四层改造

设计原则（沿用消融纪律）：不扩成新 Agent 平台，不做无上限评测；每层独立验收；保留现有结构校验门禁。

### P0 — 把"思考"接回生产链路（1~2 天，收益最大）

消融已验证、风险最低的一步：

1. **决策调用切换为非实时 Omni + `reasoning_effort=medium`**。复用消融脚本中已实测 30 次的 B 路径调用代码，实现为 `QwenThinkingDecisionProvider`（实现现有 `TeachingDecisionProvider` 接口，`workspace-teaching-decision.ts:18`），配置切换。语音播报链路（`speakDecision`，`:335-351`）不动。
2. **两段式决策**：提示词从"不输出思维链"改为两段输出——
   - `analysis`（内部，不播报）：孩子这一步实际做了什么 → 暴露哪类断点 → 本轮唯一推进点 → 准备用什么小动作；
   - `utterance`（给孩子的一到两句）：必须由 analysis 推出。
   现有 schema 的 `observation` 字段升级为真正的推理位。"先想后说"成为结构强制，而非提示词愿望。
3. **9 秒延迟的体验处理**（消融建议 #4）：收到孩子输入后立即走快速通道播一句纯承接语（不教学），思考期间 UI 显示明确思考状态，"先停一下"可取消；**不用填充语音掩盖等待**。iPad 端新增思考态 UI。
4. **超长处理改为定点改写**：超 90 字时触发"只压缩不新增结论"的改写调用，不再直接拒绝。

### P1 — 数学真值层：让低级错误在结构上不可能

1. **每个题族配确定性求解器**：泛化 `decimal-division-policy.ts` 模式。课程为固定脚本少数题族（植树、面积、小数乘除、方程），每个 probeFamily 在插件 manifest 注册 `solve()` + `verify(utterance, childState)` 钩子。算术一律精确十进制，不用 JS 浮点。
2. **复核器升级为知道答案的复核器**：把求解器完整解答注入复核 prompt（现明文禁止复核器解题），复核范围从"只查抢答"扩到"数学错误 + 抢答 + 虚构画面（对照图像清单）"。复核器可用带思考调用——不在延迟关键路径，可与 utterance 生成并行。
3. **画面虚构的机制核对**：决策引用图像内容时校验 `imageId` 是否本轮实际附带；恢复轮禁止"我看到你现在画了…"式现在时画面断言（做成校验规则，不靠自觉）。

### P2 — 思维方式教学（陶哲轩层）

**目标**：孩子逐渐把"卡住时怎么办"的思维动作变成自己的习惯，最终不经提示就会试小例子、改条件、先猜再验、回头看。验收对象是孩子的行为，不是老师的措辞。

**基准**：`docs/handoffs/2026-10-12-tao-thinking-moves.md`（八个思维动作、正反例、选动作对应表、评分量表）。本节所有改动都以它为准。

**前置**：P0 的 `analysis` 推理位；第 3 条依赖 P1 的求解器。

1. **思维动作成为决策的一等维度。** 现有 `focus`（`transformation / invariance / place_value …`）是小数除法的题型步骤，不是思维动作。决策 schema 增加两个字段：
   - `move`：老师本轮提出的动作，八选一或 `none`。孩子正顺利推进时 `none` 是正确选择。
   - `childMove`：孩子本轮自己做出的动作，可空，必须带 `evidenceIds`。

   `focus` 保留为题族内的内容锚点。`plugin-math` 的 `thinkingMoves` 从六个扩为清单里的八个，workspace 决策链路改为读取插件 manifest，不再只在旧 kernel 链路生效。

2. **提示词从规则清单重构为判断框架。** `analysis` 按四步写：
   > (1) 孩子这一轮实际做了什么，其中有没有他自己已经在用的动作 → (2) 卡在哪类断点 → (3) 按清单第三节选动作，孩子已有的动作优先跟随 → (4) 把动作落成本题上孩子能做的一个最小动作。

   `utterance` 必须由第 (4) 步推出。现有 40 多条规则分两处安置：小数除法专用规则移入该题族插件，只在该题族注入；通用纪律（字数、问号数、证据引用、不贴标签、不念动作名）移到校验层由代码强制。

3. **顺着孩子的想法检验，不对照标准解法纠正。** 孩子提出非标准做法或错误规则时，默认动作是 `specialize` 或 `justify`：找一个结果已知的小情形，让孩子用自己的办法试。这要求 P1 的求解器接口支持 `solve(variant)`，即对老师拟用的小例子或改条件版本求解，在播报前确认这个例子确实能暴露矛盾，或确实支持孩子的想法。孩子的想法成立时必须承认它成立，即使不是课本方法。

4. **老师示范"怀疑自己的结论"。** 新增 `acknowledge` 状态和处理协议：承认错误 → 问孩子是怎么发现的 → 继续。孩子的纠正记为一次 `justify` 证据。把消融中"孩子纠正 5 到 10 米间隔"固化为回归样本。

5. **用过程信号识别孩子的动作。** STROKE 时序和涂改序列压缩成事实摘要（"先写 40，涂掉，改成 24，停了 8 秒"）加入决策输入，用来填 `childMove`：涂改后重写是自检，先画小图再列式是 `represent` 或 `specialize`，长停顿是在想，不催。摘要只陈述事实，不下结论。

6. **思维动作账本，跨题跨会话。** 现有成长账本（`packages/learning-kernel/src/growth`）只接在旧 kernel 会话路由上，workspace 链路没有引用；先在 workspace 存储里做独立的轻量账本并复用其删除和保留规则，是否并入待定。每个动作记录最近的证据和撤手等级：0 未见、1 提示后做、2 一提就做、3 自发。决策输入注入两三行摘要，用途有两个：
   - **撤手**：等级 2 以上的动作不再具体提示，只问"你想先怎么试"。
   - **唤起**：引用真实证据，例如"上次植树那题你先试了短的路"。只能引用账本里存在的证据编号。

   约束：证据必须是孩子的行为，老师问过不算；不向孩子或家长输出能力标签，沿用 `forbiddenClaimPatterns`；家长可见、可更正沿用现有儿童权利机制。

7. **话保持短，实验放到画布上。** 不扩大 90 字上限。动作需要操作对象时（可压扁的平行四边形、0 到 10 米的数轴、十格条），决策附带一个 `scaffold` 请求，走现有 scaffold 通道渲染。不做自由生成绘图。已核对：workspace 的 scaffold 目前只支持线段图一种对象，且需要孩子同意；第一期只用线段图，平行四边形等新对象单独立项。

8. **验收。**
   - 用清单第五节的 T1（动作贴合）、T2（所有权）、T3（孩子接住了吗）与原有五个维度并列评分。
   - 固定样本从首轮扩为 6 到 8 轮续聊，每个题族至少一条；除失败样本外，加入清单里的正例作为正向样本。
   - 模拟孩子表达的样本只评 T1、T2；T3 和"孩子自发动作次数"只在真实孩子的会话里统计。
   - 通过线（建议值，待确认）：T1、T2 平均不低于 1.5，硬失败为 0，每条多轮样本里做对后至少出现一次 `look_back`。

**实施顺序**：1、2、4 只改 agent-host，可在固定样本上验证，先做；3 等 P1 求解器；然后 5、6；7 要动 iPad 端，放最后。

**P2 内不做**：不把八个动作排成固定流程；不向孩子念动作名；不用账本给孩子评级或排名。

### P3 — 验证体系（与 P0 同步开始）

1. 按消融建议 #2：把 **B 面积抢答、A 反复求助不响应、C 虚构画面**三类新失败固化为回归样本，进固定样本集。每层改动都在同一固定样本集上跑对照后再谈生产切换（消融建议 #5）。
2. 真机验证：P0 的思考等待体验（约 9 秒）必须 USB 连 iPad Pro 实测——承接语 + 思考态 UI + 可取消在孩子视角是否自然。复用现有 `apps/ipad/ScholarPadProbe` 探针 App 与 `#if DEBUG` 合成语音回放夹具。

## 三、明确不做

- 不换语音模型、不动 realtime 语音传输链路（消融已确认压缩提示省用量但降质量）。
- 不扩大播报字数上限；超长走定点改写。
- 不引入第二家模型供应商或新平台。
- 不承诺"切换 thinking 模型即解决教学质量"——P0 是必要条件，P1/P2 才是教学深度来源。

## 四、实施入口（P0 改动位置）

- `apps/agent-host/src/ai/workspace-teaching-decision.ts`：新增 thinking provider + 两段式 decision schema（`analysis`/`utterance`）。
- `apps/agent-host/src/ai/workspace-voice-route.ts`：快速承接语 + 思考态事件。
- `apps/ipad`：`LearningWorkspaceView` 思考态 UI。
- 验证：回归样本集 + USB 真机等待体验验收。

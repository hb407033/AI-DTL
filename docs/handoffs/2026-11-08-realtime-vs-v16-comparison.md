v16 宿主日志里的时间，是“整段孩子音频已经在宿主手里之后，转写用时 + 下一次出声调用到首包”。它不含中间文字决策的等待，也不是 iPad 扬声器出声。全部 15 段的中位数是 2271 毫秒。分题中位数：乘法 2358（6 段）、除法 2380（1）、方程 2392（1）、面积 2253（4）、植树 2269（3）。

v16 token 来自隔离目录里的 `usage.jsonl`，只加 `total_tokens`。转写调用的 usage 是空的，没有把空值当成 0 以外的数，也没有把空值加进去。合计：乘法 58162（29 次调用，6 次空 usage）、除法 33179、方程 20958、面积 39850、植树 38258。按已经写下的老师句子平均，大约是乘法 8309、除法 16590、方程 20958、面积 7970、植树 9565。重试会让没走完的题显得特别高。

## 实时路径

Debug 已重新安装，用来把 token 和出声时间记进回合。控制台原文：

`AIDTL-REALTIME unavailable`

随后宿主日志出现了 v16 的 `workspaceProviderTiming`，说明没有密钥时 App 回到了主机对话。这次启动的验收宿主是 PID `64071`，已经停掉，8797/8798 空闲。它在停掉前写下 14015 token，这是回退后的 v16 调用，不是实时对照，不拿来算门槛。更早一次启动参数被 `devicectl` 吃掉，宿主 PID `63797` 也已停，没有产生调用。没有发放口令，没有领取密钥。

`devicectl` 会把 `-realtimeMode` 拆成自己的短选项，其中的 `-t` 还要一个秒数，参数到不了 App。实时开关只放在这一次启动的环境变量 `AI_DTL_REALTIME_MODE=YES` 里，不写家长设置的默认值。
